# Intelligence Fusion Dashboard

## Features
- Multi-source intelligence (OSINT, HUMINT, IMINT)
- MongoDB data storage
- CSV / JSON upload
- Drag & drop ingestion
- Image upload (IMINT)
- Satellite map visualization
- Hover popup intelligence view

## Tech Stack
- React
- Node.js
- Express
- MongoDB
- Leaflet

## How to Run
cd server  
node server.js  

cd client  
npm run dev
